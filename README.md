# Çamaşır İpindeki Tek Çorabın Bağımsızlık Bildirgesi

> **Resmi Uyarı:** Bu yazılım bir şaka değildir. Çamaşır ipinde tek kalan çorap, 17 Eylül 2026 itibarıyla egemen bir varlıktır. Çiftini aramak için diplomatik nota şarttır.

## Bu nedir?

Türkiye Cumhuriyeti çamaşır ipleri üzerinde yüzyıllardır süren **tek çorap sorunu** nihayet hukuki bir çözüme kavuşmuştur.

Bu yazılım:

1. Tek çorabın kimlik belgesini basar.
2. Egemenlik katsayısını hesaplar (rüzgâr + mandal sıkılığı + güneş açısı).
3. Çift çorap birleşme tekliflerini reddeder.
4. Komşu balkona resmi protesto notu üretir.
5. Çorabın BM'ye (Balkon Milletleri) üye başvurusunu doldurur.

## Kurulum

```bash
python3 corap_cumhuriyeti.py
```

Bağımlılık yoktur. Çorap zaten yeterince yalnızdır.

## Kullanım

Program sorduğunda:
- Çorabın rengi
- Kaç gündür ipte asılı kaldığı
- Mandal tipi (ahşap / plastik / kayıp)
- Komşunun balkonu açık mı

bilgilerini girin. Yazılım size **Bağımsızlık Fermanı** basacaktır.

## Anayasa (kısa)

- Madde 1: Çorap tektir, çift değildir, çift olmayacaktır.
- Madde 2: Egemenlik kayıtsız şartsız mandaldadır.
- Madde 3: Çamaşır makinesi işgalci bir aktördür.
- Madde 4: Rüzgâr dış politika aracıdır.
- Madde 5: Kaybolan çift, tarihsel bir travmadır; anılır, aranmaz.

## Sık sorulan sorular

**Çorabın çiftini bulursam ne olur?**  
Yazılım çöker. Bu bir özelliktir.

**Neden Türkçe?**  
Çünkü çamaşır ipi evrenseldir ama utancı yerlidir.

**Bu siyasi mi?**  
Hayır. Bu çoraptır. Siyaset çoraptan öğrenir, tersi değil.  
*(Bazı satırların altında ISO-CORAP-404 sağlama toplamı vardır. Okumayın. Ciddiyet bozulur.)*
